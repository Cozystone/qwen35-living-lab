# qwen35-living-lab

작은 LLM(Qwen3.5-4B / 9B)이 한 대의 컴퓨터에서 기억을 가지고 "계속 살아가게" 하는 실험의 기록이다.
LLM 부품을 ATANOR 모듈로 하나씩 바꿔 가며(테세우스의 배) 어떤 부품에 실제 능력이 있는지 재려고 했다.
2026-10-26 ~ 27 에 진행했고, 사전 등록 기준으로 **실패 판정을 내리고 종료**했다.

## 결론 요약
- **기억은 효과가 있다.** 기억을 유지한 조건(LIFE)이 매일 기억을 지운 조건(FRESH)보다 꾸준히 낫다. 3일 세계 8.36 대 5.45, 12점 만점.
- **프롬프트 규칙은 효과가 없고, 코드로 강제한 점검은 효과가 있다.** 코드 점검을 넣자 지어낸 이름이 9/11 에서 0/11 로 줄었다.
- **모델을 4B 에서 9B 로 키우면 판단 습관은 나아진다. 총점과 반복 고리는 그대로다.** ([reports/SIZE_STUDY.md](reports/SIZE_STUDY.md))
- **agent-v5(계획→실행→점검)는 불합격이다.** 7일 세계에서는 나았지만, 사전 등록한 3일 세계 기준을 넘지 못했다. ([reports/V5_RESULT.md](reports/V5_RESULT.md))
- **ATANOR 단독(M1)은 정직한 손이다.** 엉뚱한 행동은 0 이다. 하지만 교사 없이는 아무것도 못 하고 한국어를 이해하지 못한다. ([reports/TRACK_A_M1.md](reports/TRACK_A_M1.md))
- **R1(LLM 이 의도를 정하고 ATANOR 가 실행)은 불합격이다.** 손은 정확했지만 지시가 틀려, 엉뚱한 곳으로 간 파일이 두 배가 됐다. 병목은 실행이 아니라 의도 해석이다. ([reports/R1_RESULT.md](reports/R1_RESULT.md))

## 구성
- `HANDOFF.md`, `WORKLOG.txt`: 전체 인계서와 작업 일지(명령·경로·해시).
- `life/`: 생활 루프 에이전트(`agent.py` v2~v5, v4a), 세계(`world.py` 3일, `world_v2.py` 7일), 실행·집계 스크립트.
  - `life/trackA/`: ATANOR 브리지, 진실 교사, ATANOR 손(R1), 동결 프로토콜.
- `atanor_trackA/`: ATANOR 저장소에 더한 새 몸 `home` 과 raw_obs 변경 diff. ATANOR 코어는 이 저장소에 없다.
- `reports/`: 각 실험의 사전 등록, 결과, 표.
- `eval/`: 양자화·속도·근거화 평가 결과(RESULTS.md).
- `tools/scripts/`: 변환·평가·근거화 검색(위키백과)·읽기 전용 게이트웨이 스크립트.
- `laptop/`: 격리 실험 노트북(Debian) 설치 계획과 설정 스크립트.
- `runs/`: 실험 실행 결과(results.json, 걸음 기록).

## 올리지 않은 것
- 모델 가중치(GGUF, 병합본, LoRA 어댑터).
- 거절 시험용 유해 질문에 대한 모델 응답 기록.
- 위키백과 응답 캐시, 하드웨어 식별 정보, 개인 파일 목록.
