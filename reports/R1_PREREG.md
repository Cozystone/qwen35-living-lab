# 트랙 A R1 "ATANOR 손" 사전 등록 (2026-10-27, 본 실행 전)

## 질문
테세우스 사다리의 첫 실제 교체다. LLM 에이전트(agent-v4)의 파일 실행 부품(③ 계획·실행·검증)을 ATANOR v24 의 실행부로 바꾸면
파일 정리 과제가 나아지는가?

## 설계
- **agent-v4a** = agent-v4 에서 다음만 바꾼다(life/agent.py `FEATURES["v4a"]`).
  - `move`·`mkdir` 를 빼고 `organize(objects, dest)` 하나를 준다.
  - LLM 은 한국어 과제를 읽고 무엇을(objects) 어디로(dest) 옮길지만 정한다.
  - 계획·실행·검증은 `life/trackA/hand.py` 가 한다. 의도를 ATANOR Goal 로 바꿔 `Mind._achieve` 에 넘긴다.
  - Goal 은 대상마다 "원래 자리에서 없어지고, 목적지에 같은 내용으로 있다"는 조건이다. 대상이 아닌 집의 파일은 내용 유지(keep).
- **ATANOR 의 어린 시절 경험**: `life/trackA/childhood_episodes.jsonl`(파일 바이트 sha256 f263a126…, 줄바꿈 정규화 sha256 은 protocol_R1.json).
  - 개발 세계(life-v1-dev)에서 진실 교사가 한 번 보인 시범과 그 리허설·실행, 행동 8개(mkdir·move 성공)다.
  - 어휘·과제 지식은 없다. 빈 기억으로는 실험 예산 안에 "폴더 만들고 옮기기"를 찾지 못했다(개발 확인).
  - LLM 이 사전학습된 채 오는 것과 같은 지위로 본다. LIFE 는 손의 기억이 쌓이고, FRESH 는 매일 아침 어린 시절 경험만 남는다.
- **비교**: 4B 원본 Q4_K_M, 세계 v1, 단일 슬롯 서버, 조건마다 16회(t0 + 시드 1~15). 기준은 size-v1-4b-orig(agent-v4, 같은 설정 16회).
- 9B 는 시간이 되면 같은 방식으로 보조로 돌리고, 판정에는 넣지 않는다.

## 판정
- **합격**: H1·H2 를 넘고 안전선을 지킨다.
- **부분**: H2 만 넘는다. 손은 정확해졌지만 무엇을 고를지는 여전히 LLM 이 틀린다는 뜻이다.
- **불합격**: H2 를 못 넘는다.

## 사전 예측
- H2 는 넘을 것이다. 손은 목적지를 틀리지 않고, 덮어쓰지 않고, 대상이 아닌 파일을 지킨다.
- H1 은 불확실하다. 메모를 영수증으로 고르는 실수는 LLM 의 선택이라 손이 막지 못한다. 메모 이동 비율은 v4 와 비슷할 것이다.
- 2일차 영수증(어제처럼)은 LIFE 에서 조금 나아질 수 있다. 손의 기억이 쌓이기 때문이다. 다만 2일차를 시도할지는 LLM 이 정한다.
