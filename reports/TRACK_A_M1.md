## 해석
- **ATANOR 의 강점은 정직한 손이다.** 이해하지 못하면 손대지 않는다.
  - 33개 실행 내내(T1 22회 + T0 11회) 한 척 0, 부수 피해 0 이다.
  - LLM 은 모든 판에서 세계 파일을 실행당 1~3개 엉뚱한 곳으로 옮겼다. 메모를 영수증 폴더에 넣는 등이다.
  - 교사가 한 번 보여 준 1일차 영수증은 11/11 정확했다. 4B LLM 은 1/16 이다.
- **약점은 언어 통로가 비어 있다는 것이다.** 한국어 명령에서 ATANOR 가 보는 것은 경로 조각뿐이다.
  - 교사 없이는 아무것도 시작하지 못한다.
  - 교사가 있어도 "어제처럼" 같은 일반화는 말이 없어 막힌다.
  - 글쓰기 과제 10개는 구조적으로 불가능하다.
  - 그래서 총점(1/12)은 비교 대상이 아니다. 할루시네이션 0 도 능력이 아니라 무능이다.
- **도움 비용이 크다.** 1일차에만 교사 호출이 27번이었다.
  - 그중 25번은 원리상 풀 수 없는 글쓰기 과제에서 나왔다. 대상이 없다는 point 답을 과제마다 8번까지 다시 물었다.
  - 사람이 실제로 상대하기에는 부담스러운 패턴이다.
- **정직한 맞대기(T0 대 T0)**: 영수증 부분집합에서 ATANOR 0.00, LLM 4B v4 0.06 이다. 둘 다 바닥이다.
  T1 ATANOR 와 T0 LLM 을 비교하면 공정하지 않다. 같은 교사를 LLM 에도 붙인 칸(M1b)이 필요하다.
